01. 함수
함수는 입력을 받아 작업을 수행하고 결과를 반환합니다. 매개변수의 기본값과 반환값을 구분하세요.
[코드]
def calc(x, y=2):
    return x * y + 1

print(calc(3), calc(3, 4))
[문제] 올바른 출력을 하나 고르시오.
1. 6 12
2. 7 7
3. 7 13
4. 9 13
5. 13 7
정답: 3번
실제 출력: 7 13
[상세 풀이]
calc(3)은 y의 기본값 2를 사용하므로 3×2+1=7입니다. calc(3, 4)는 y=4이므로 3×4+1=13입니다. print는 두 값을 공백으로 구분합니다. 함수 내부에서 반환하는 것과 화면에 출력하는 것은 서로 다릅니다.

02. 재귀함수
재귀함수는 자기 자신을 호출합니다. 종료 조건과 호출이 되돌아오는 순서를 추적하세요.
[코드]
def f(n):
    if n <= 1:
        return 1
    return n + f(n - 2)

print(f(5))
[문제] 올바른 출력을 하나 고르시오.
1. 5
2. 8
3. 15
4. 9
5. 6
정답: 4번
실제 출력: 9
[상세 풀이]
f(5)=5+f(3), f(3)=3+f(1)입니다. f(1)은 종료 조건에 따라 1을 반환하므로 합은 5+3+1=9입니다. 매번 2씩 감소하므로 4와 2를 더하지 않습니다. 종료 조건이 없으면 재귀 호출이 정상적으로 끝나지 않을 수 있습니다.

03. 큐
큐는 먼저 들어온 항목이 먼저 나오는 FIFO 자료구조입니다.
[코드]
from collections import deque
q = deque([2, 4])
q.append(6)
x = q.popleft()
q.append(x + 1)
print(list(q))
[문제] 올바른 출력을 하나 고르시오.
1. [4, 6, 3]
2. [2, 4, 3]
3. [3, 4, 6]
4. [2, 4, 6]
5. [6, 4, 3]
정답: 1번
실제 출력: [4, 6, 3]
[상세 풀이]
초기 큐 [2, 4]의 오른쪽에 6을 넣으면 [2, 4, 6]입니다. popleft()는 왼쪽의 2를 꺼내 x에 저장하므로 [4, 6]이 남습니다. x+1인 3을 오른쪽에 넣으면 [4, 6, 3]입니다. 스택과 달리 가장 오래된 항목이 먼저 제거됩니다.

04. 스택
스택은 나중에 들어온 항목이 먼저 나오는 LIFO 자료구조입니다.
[코드]
s = [1, 3]
s.append(5)
x = s.pop()
s.append(x - 2)
print(s, s.pop())
[문제] 올바른 출력을 하나 고르시오.
1. [1, 3, 3] 3
2. [1, 3] 5
3. [1] 3
4. [3, 1] 3
5. [1, 3] 3
정답: 5번
실제 출력: [1, 3] 3
[상세 풀이]
5를 넣고 pop()하면 x=5, s=[1, 3]입니다. 3을 다시 넣어 [1, 3, 3]이 됩니다. 마지막 print의 인수는 왼쪽부터 평가되지만 첫 인수는 리스트의 복사본이 아니라 같은 객체에 대한 참조입니다. 두 번째 인수 s.pop()이 3을 제거한 뒤 실제 출력이 수행되므로 리스트는 [1, 3]으로 표시됩니다.

05. 그래프
무방향 그래프의 인접 리스트에는 한 간선이 양쪽 정점에 각각 기록됩니다.
[코드]
g = {
    'A': ['B', 'C'],
    'B': ['A', 'C'],
    'C': ['A', 'B', 'D'],
    'D': ['C']
}
print(sum(len(v) for v in g.values()) // 2)
[문제] 올바른 출력을 하나 고르시오.
1. 8
2. 4
3. 3
4. 5
5. 6
정답: 2번
실제 출력: 4
[상세 풀이]
각 정점의 차수는 A=2, B=2, C=3, D=1로 합은 8입니다. 자기 루프가 없는 이 무방향 그래프에서는 각 간선이 두 번 기록되므로 간선 수는 8÷2=4입니다. 실제 간선은 AB, AC, BC, CD입니다. 유향 그래프에는 이 나누기 2 규칙을 그대로 적용하지 않습니다.

06. 트리
트리의 높이를 재귀적으로 구합니다. 이 코드에서는 빈 트리 높이를 0, 잎 노드 높이를 1로 정의합니다.
[코드]
tree = {'A': ['B', 'C'], 'B': ['D'],
        'C': [], 'D': []}

def height(v):
    if not tree[v]:
        return 1
    return 1 + max(height(c) for c in tree[v])

print(height('A'))
[문제] 올바른 출력을 하나 고르시오.
1. 1
2. 2
3. 4
4. 3
5. 0
정답: 4번
실제 출력: 3
[상세 풀이]
D와 C는 자식이 없어 높이가 1입니다. B는 D를 자식으로 가지므로 1+1=2이고, A는 max(2, 1)+1=3입니다. 가장 긴 경로 A→B→D에 있는 노드 수가 3입니다. 간선 수로 높이를 정의하면 2이지만 이 코드는 노드 수 기준입니다.

07. 탐색 알고리즘
이진 탐색은 정렬된 배열에서 탐색 구간을 절반씩 줄입니다. 인덱스는 0부터 시작합니다.
[코드]
a = [2, 5, 8, 11, 14, 17, 20]
lo, hi = 0, len(a) - 1
count = 0
while lo <= hi:
    mid = (lo + hi) // 2
    count += 1
    if a[mid] == 14:
        break
    if a[mid] < 14:
        lo = mid + 1
    else:
        hi = mid - 1
print(mid, count)
[문제] 올바른 출력을 하나 고르시오.
1. 4 3
2. 4 2
3. 5 3
4. 3 4
5. 14 3
정답: 1번
실제 출력: 4 3
[상세 풀이]
첫 중간 인덱스는 3이며 값 11이 작으므로 lo=4입니다. 다음 중간 인덱스는 5이며 값 17이 크므로 hi=4입니다. 세 번째 중간 인덱스 4에서 14를 찾습니다. 따라서 mid=4, count=3입니다. 출력하는 것은 찾은 값 자체가 아니라 인덱스와 반복 횟수입니다.

08. 백트래킹
선택하고 재귀 호출한 뒤 선택을 취소하여 다른 경우를 탐색합니다.
[코드]
result = []

def search(path):
    if len(path) == 2:
        result.append(''.join(map(str, path)))
        return
    for x in [1, 2, 3]:
        if x not in path:
            path.append(x)
            search(path)
            path.pop()

search([])
print(len(result), result[2])
[문제] 올바른 출력을 하나 고르시오.
1. 9 13
2. 6 23
3. 6 21
4. 3 31
5. 6 12
정답: 3번
실제 출력: 6 21
[상세 풀이]
중복 선택을 막으므로 길이 2의 순열 3×2=6개를 만듭니다. 깊이 우선 탐색의 생성 순서는 12, 13, 21, 23, 31, 32입니다. 인덱스 2는 세 번째 항목인 문자열 21입니다. path.pop()으로 직전 선택을 취소해야 다음 가지가 독립적으로 탐색됩니다.

09. 가지치기
가능성이 없는 탐색 가지를 조기에 중단합니다. 여기서는 남은 수가 모두 양수라는 조건이 중요합니다.
[코드]
nums = [2, 3, 4]
visits = 0

def search(i, total):
    global visits
    visits += 1
    if total > 4:
        return
    if i == len(nums):
        return
    search(i + 1, total + nums[i])
    search(i + 1, total)

search(0, 0)
print(visits)
[문제] 올바른 출력을 하나 고르시오.
1. 15
2. 8
3. 7
4. 11
5. 13
정답: 5번
실제 출력: 13
[상세 풀이]
visits는 가지치기 판단 전에 증가하므로 바로 중단되는 호출도 셉니다. 깊이별 호출 수는 i=0에서 1, i=1에서 2, i=2에서 4입니다. i=2의 합 5인 호출은 가지치기되어 자식을 만들지 않고 합 2, 3, 0인 세 호출만 각각 자식 2개를 만듭니다. 따라서 1+2+4+6=13입니다. 가지치기가 없으면 15번입니다. 남은 수가 양수이므로 이미 4를 초과한 합은 다시 4 이하가 되지 않습니다.

10. 탐욕법
매 순간 가장 좋아 보이는 선택을 합니다. 탐욕적 선택이 항상 전역 최적해를 보장하지는 않습니다.
[코드]
amount = 6
count = 0
for coin in [4, 3, 1]:
    count += amount // coin
    amount %= coin
print(count)
[문제] 올바른 출력을 하나 고르시오.
1. 2
2. 3
3. 1
4. 4
5. 6
정답: 2번
실제 출력: 3
[상세 풀이]
4원을 1개 선택하면 잔액은 2원입니다. 3원은 사용할 수 없고 1원을 2개 선택하므로 총 3개입니다. 하지만 3원 두 개라면 2개로 지불할 수 있습니다. 이 코드는 탐욕법의 결과를 출력하는 것이지 최적 동전 수를 출력한다고 보장하지 않습니다.

11. 문제분해
큰 작업을 입력 정리, 조건 판별, 집계 등 작은 함수로 나누어 해결합니다.
[코드]
def parse(text):
    return list(map(int, text.split()))

def select(values):
    return [x for x in values if x % 2 == 0]

def solve(text):
    return sum(select(parse(text)))

print(solve('3 4 6 7'))
[문제] 올바른 출력을 하나 고르시오.
1. 20
2. 2
3. 4
4. 10
5. 13
정답: 4번
실제 출력: 10
[상세 풀이]
parse는 문자열을 [3, 4, 6, 7]로 바꿉니다. select는 짝수만 남겨 [4, 6]을 반환합니다. solve는 이를 합산해 10을 반환합니다. 이렇게 역할별로 함수를 분리하면 입력 처리와 조건 필터링을 각각 독립적으로 테스트하기 쉽습니다.

12. 분할 정복법
문제를 작은 부분 문제로 나누고, 각각 해결한 결과를 결합합니다.
[코드]
def solve(a):
    if len(a) == 1:
        return a[0]
    mid = len(a) // 2
    left = solve(a[:mid])
    right = solve(a[mid:])
    return max(left, right)

print(solve([7, 2, 9, 4]))
[문제] 올바른 출력을 하나 고르시오.
1. 9
2. 22
3. 7
4. 4
5. 2
정답: 1번
실제 출력: 9
[상세 풀이]
[7, 2]와 [9, 4]로 분할합니다. 각 부분은 다시 원소 하나씩으로 나뉘며 종료 조건에서 원소를 반환합니다. 첫 부분은 max(7, 2)=7, 둘째 부분은 max(9, 4)=9이고 마지막 결합 결과는 max(7, 9)=9입니다. 이 함수는 합이 아니라 최댓값을 구하며 빈 리스트는 입력하지 않는다는 전제가 있습니다.

13. 동적계획법
중복되는 부분 문제의 답을 저장하여 재사용합니다.
[코드]
n = 5
dp = [0] * (n + 1)
dp[0] = 1
for i in range(1, n + 1):
    dp[i] = dp[i - 1]
    if i >= 2:
        dp[i] += dp[i - 2]
print(dp[n])
[문제] 올바른 출력을 하나 고르시오.
1. 5
2. 13
3. 8
4. 3
5. 10
정답: 3번
실제 출력: 8
[상세 풀이]
1칸 또는 2칸씩 올라가는 순서를 세는 점화식입니다. 아무것도 하지 않는 방법을 1개로 보아 dp[0]=1입니다. dp[1]=1, dp[2]=2, dp[3]=3, dp[4]=5, dp[5]=8입니다. 마지막 이동이 1칸인 경우와 2칸인 경우를 더합니다. 배열에 이전 답을 저장해 중복 계산을 피합니다.

14. 빅오법
빅오 표기법은 입력 크기에 따른 연산량의 증가 상한을 나타냅니다. 출력은 실제 실행 횟수입니다.
[코드]
n = 8
count = 0
for i in range(n):
    j = 1
    while j < n:
        count += 1
        j *= 2
print(count)
[문제] 올바른 출력을 하나 고르시오.
1. 64
2. 8
3. 32
4. 16
5. 24
정답: 5번
실제 출력: 24
[상세 풀이]
각 바깥 반복에서 j는 1, 2, 4일 때 실행되고 8이 되면 종료하므로 내부 반복은 3번입니다. 바깥 반복은 8번이므로 count=8×3=24입니다. 일반적인 n≥2에서 반복 횟수는 n×ceil(log₂n)이므로 시간 복잡도는 O(n log n)이며, 더 정확한 점근적 차수는 Θ(n log n)입니다. 반복문 두 개가 있다고 항상 O(n²)인 것은 아닙니다.

15. 문제발견
관찰한 자료에서 해결해야 할 이상 상태를 찾아 문제로 정의합니다. 경계값의 포함 여부를 확인하세요.

waits = [3, 12, 7, 15, 10]

problems = [i + 1 for i, t in enumerate(waits)

문제 상황을 대기 시간이 10을 초과하는 경우로 정의했습니다. 12와 15가 해당하며 각각 두 번째와 네 번째 기록입니다. enumerate의 인덱스는 0부터 시작하므로 i+1로 기록 번호를 만듭니다. 10은 초과가 아니라 같음이므로 포함되지 않습니다. 문제 기준을 명확히 정해야 이후 설계와 평가도 일관됩니다.

16. 설계
구현 전에 조건의 우선순위와 경계값을 명확히 설계합니다.
[코드]
def fee(age):
    if age < 8:
        return 0
    elif age < 19:
        return 700
    return 1200

print(fee(7), fee(8), fee(19))
[문제] 올바른 출력을 하나 고르시오.
1. 0 0 700
2. 700 700 1200
3. 0 700 700
4. 0 700 1200
5. 0 1200 1200
정답: 4번
실제 출력: 0 700 1200
[상세 풀이]
7은 첫 조건 age<8을 만족해 0입니다. 8은 첫 조건은 거짓이지만 age<19를 만족하여 700입니다. 19는 두 조건 모두 거짓이므로 1200입니다. 구간 설계는 8 미만, 8 이상 19 미만, 19 이상입니다. 경계값 8과 19를 검토하는 것이 중요합니다.

17. 구현
설계를 코드로 옮길 때 인덱스와 반복 범위를 정확하게 표현해야 합니다.

values = [2, 4, 6]
prefix = [0]
for x in values:
    prefix.append(prefix[-1] + x)
print(prefix[3] - prefix[1])

1. 10
2. 12
3. 6
4. 8
5. 4
정답: 1번
실제 출력: 10
[상세 풀이]
누적합 배열은 처음 [0]에서 [0, 2], [0, 2, 6], [0, 2, 6, 12]로 변합니다. prefix[3]-prefix[1]=12-2=10입니다. 처음 세 원소의 합에서 처음 한 원소의 합을 빼므로 values 인덱스 1부터 2까지, 즉 4+6의 합을 구합니다. 누적합 배열을 앞에 0을 붙여 구현하면 구간 계산이 단순해집니다.

18. 협업
팀원이 만든 함수들을 연결할 때 입력·출력 형식과 원본 변경 여부를 합의해야 합니다.
[코드]
def member_a(data):
    return sorted(data)

def member_b(data):
    return data[0] + data[-1]

raw = [5, 1, 3]
print(member_b(member_a(raw)), raw)
[문제] 올바른 출력을 하나 고르시오.
1. 8 [1, 3, 5]

19. 테스트
테스트는 실제 실행 결과를 기대 결과와 비교합니다. 일부 테스트 통과가 완전한 정확성을 뜻하지는 않습니다.
[코드]
def absolute(x):
    return x if x > 0 else -x

cases = [(-3, 3), (0, 0), (2, 2), (-1, -1)]
passed = 0
for value, expected in cases:
    if absolute(value) == expected:
        passed += 1
print(passed, len(cases) - passed)
[문제] 올바른 출력을 하나 고르시오.
1. 4 0
2. 2 2
3. 1 3
4. 0 4
5. 3 1
정답: 5번
실제 출력: 3 1
[상세 풀이]
-3, 0, 2의 실제 반환값은 각각 3, 0, 2로 기대값과 같습니다. -1의 실제 반환값은 1인데 기대값을 -1로 적었으므로 마지막 비교는 실패합니다. 통과 3개, 실패 1개를 출력합니다. 이 사례는 구현이 아니라 테스트의 기대값에 오류가 있을 수 있음을 보여줍니다.

results = [('A', 90, 12), ('B', 90, 8), ('C', 85, 5)]
ranked = sorted(results, key=lambda r: (-r[1], r[2]))

21. 종합
입력 정리, 자료구조 선택, 정렬, 추출을 하나의 처리 과정으로 연결합니다.
[코드]
def summarize(text, k):
    values = list(map(int, text.split()))
    unique = sorted(set(values), reverse=True)
    return sum(unique[:k])

print(summarize('4 7 4 2 9 7', 3))
[문제] 올바른 출력을 하나 고르시오.
1. 23
2. 18
3. 33
4. 20
5. 16
정답: 4번
실제 출력: 20
[상세 풀이]
문자열을 정수 리스트로 바꾸고 set으로 중복을 제거한 뒤 내림차순 정렬하면 [9, 7, 4, 2]입니다. [:3]은 앞의 세 값 [9, 7, 4]이고 합은 20입니다. 중복을 제거하지 않은 상위 세 값 9, 7, 7의 합 23과 구별해야 합니다. 여러 개념을 결합한 처리 순서가 결과를 결정합니다.

22. 성찰
수정 전후의 결과를 비교하고 실패 원인을 돌아봅니다. 제한된 사례의 개선을 전체 정확성으로 일반화하지 마세요.
[코드]
def old(n):
    return sum(range(n))

def new(n):
    return sum(range(1, n + 1))

cases = [(1, 1), (3, 6), (5, 15)]
before = sum(old(n) == expected for n, expected in cases)
after = sum(new(n) == expected for n, expected in cases)
print(before, after)
[문제] 올바른 출력을 하나 고르시오.
1. 0 3
2. 3 3
3. 1 3
4. 0 2
5. 3 0
정답: 1번
실제 출력: 0 3
[상세 풀이]
목표는 1부터 n까지의 합입니다. old는 0부터 n-1까지 더해 n=1, 3, 5에서 각각 0, 3, 10이므로 모두 실패합니다. new는 1부터 n까지 더해 1, 6, 15가 되어 모두 통과합니다. 비교식의 True는 합산에서 1, False는 0으로 계산됩니다. 범위 끝값을 포함하지 않는 range의 특성을 성찰하고 수정했지만 세 사례만으로 모든 입력의 정확성을 증명한 것은 아닙니다.
