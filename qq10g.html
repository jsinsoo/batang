공통 핵심 원리

\(g'(f(x))f'(x)=(g\circ f)'(x)\) 이므로 절댓값 정적분은 합성함수의 총변동량을 나타냅니다.

\[\int_b^{b+1/\sqrt c}f(g(x))g'(x)\,dx=\int_0^1f(u)\,du\]

이 문제군에서 \(a\)는 양의 정수, \(b,c\)는 자연수입니다. 따라서 합성함수의 총변동량을 계산할 수 있습니다.

문항 1 유형 변형 1

양의 정수 \(a\), 자연수 \(b,c\)에 대하여 두 함수

\[f(x)=-\sin(ax)+b+1,\qquad g(x)=c(x-b)^2\]

가 다음 조건을 만족한다.

\[\int_0^{2\pi}\left|g'(f(x))f'(x) \right|\,dx=8,\qquad c=1\]
\[\int_b^{b+1/\sqrt c}f(g(x))g'(x)\,dx=2+\frac{\cos 1-1}{1}.\]

위 조건에서 \(f(2\pi)=\frac qp\) (서로소인 자연수 \(p,q\))일 때 \(p+q\)를 구하시오.

단계별 상세 풀이 및 정답

1단계. 합성함수는 \(g(f(x))=c(1-\sin(ax))^2\) 입니다.

2단계. 연쇄법칙을 적용하면

\[g'(f(x))f'(x)=-2ca(1-\sin(ax))\cos(ax).\]

3단계. \(1-\sin(ax)\ge0\)이므로

\[|g'(f(x))f'(x)|=2ca(1-\sin(ax))|\cos(ax)|.\]

4단계. \(a\)가 양의 정수이면 \(0\le x\le2\pi\)에서 \(\sin(ax)\)는 정확히 \(a\)회 진동합니다.

5단계. 한 주기 동안 \(c(1-\sin(ax))^2\)의 최솟값은 0, 최댓값은 \(4c\)입니다. 한 주기 총변동량은 \(8c\)입니다.

6단계. 따라서 첫 적분은 \(8ca=8\)이고, \(c=1\)를 대입하여 \(a=1\)를 얻습니다.

7단계. 두 번째 적분에 \(u=g(x)=c(x-b)^2\)를 치환하면 \(u\)의 범위는 0부터 1까지입니다.

\[\int_0^1(-\sin(au)+b+1)\,du=b+1+\frac{\cos a-1}{a}.\]

8단계. 주어진 두 번째 조건과 비교하면 \(b=1\)입니다. (첫 적분으로 구한 \(a\) 사용)

9단계. \(a\)가 정수이므로 \(\sin(2\pi a)=0\)입니다.

\[f(2\pi)=-\sin(2\pi\cdot 1)+1+1=2=\frac{2}{1}.\]

10단계. \(p=1, q=2\)이므로 정답 \(\boxed{p+q=3}\)입니다.

Python 검산 코드와 예상 출력
import math

a, b, c = 1, 1, 1
def f(x):
    return -math.sin(a*x) + b + 1
def g(x):
    return c*(x-b)**2
def fp(x):
    return -a*math.cos(a*x)
def gp(x):
    return 2*c*(x-b)
def simpson(fun, lo, hi, n=20000):
    h = (hi-lo)/n
    s = fun(lo)+fun(hi)
    for k in range(1,n):
        s += (4 if k%2 else 2)*fun(lo+k*h)
    return s*h/3

I1 = simpson(lambda x: abs(gp(f(x))*fp(x)), 0, 2*math.pi)
I2 = simpson(lambda x: f(g(x))*gp(x), b, b+1/math.sqrt(c))
print('첫째 적분:', round(I1, 7), '이론값:', 8)
print('둘째 적분:', round(I2, 7))
print('둘째 적분 이론값:', round(b+1+(math.cos(a)-1)/a, 7))
print('f(2π):', round(f(2*math.pi), 7))
print('p+q:', 3)

Simpson 수치적분으로 두 적분과 최종 답을 확인합니다. 출력값은 부동소수점 오차에 따라 마지막 자리가 달라질 수 있습니다.

import numpy as np
import matplotlib.pyplot as plt

# 문항 1 : 함수와 정적분 그래프
# 설치: pip install numpy matplotlib
# 한글 제목 출력 (Windows)
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

a, b, c = 1, 1, 1
f = lambda x: -np.sin(a*x) + b + 1
g = lambda x: c*(x-b)**2
fp = lambda x: -a*np.cos(a*x)
gp = lambda x: 2*c*(x-b)

x = np.linspace(0, 2*np.pi, 2001)
t = np.linspace(b, b + 1/np.sqrt(c), 1001)
y1 = f(x)
y2 = g(f(x))
y3 = np.abs(gp(f(x))*fp(x))
y4 = f(g(t))*gp(t)

fig, axes = plt.subplots(2, 2, figsize=(12, 8))
items = [
    (axes[0,0], x, y1, 'f(x)', 'royalblue'),
    (axes[0,1], x, y2, 'g(f(x))', 'crimson'),
    (axes[1,0], x, y3, '|g\'(f(x)) f\'(x)|', 'seagreen'),
    (axes[1,1], t, y4, 'f(g(x)) g\'(x)', 'darkviolet'),
]
for ax, xx, yy, title, color in items:
    ax.plot(xx, yy, color=color, linewidth=2)
    ax.set_title(title)
    ax.axhline(0, color='gray', linewidth=0.8)
    ax.grid(alpha=0.25)
axes[1,0].fill_between(x, 0, y3, alpha=0.18, color='seagreen')
axes[1,1].fill_between(t, 0, y4, alpha=0.18, color='darkviolet')
fig.tight_layout()
plt.savefig('문항01_함수그래프.png', dpi=180, bbox_inches='tight')
plt.show()

# 수치 적분 확인 (NumPy 2.x에서도 사용 가능)
print('첫 번째 적분 ≈', np.trapezoid(y3, x))
print('두 번째 적분 ≈', np.trapezoid(y4, t))
print('f(2π) ≈', f(2*np.pi))

Python 검산 코드와 예상 출력
import math

a, b, c = 10, 4, 2
def f(x):
    return -math.sin(a*x) + b + 1
def g(x):
    return c*(x-b)**2
def fp(x):
    return -a*math.cos(a*x)
def gp(x):
    return 2*c*(x-b)
def simpson(fun, lo, hi, n=20000):
    h = (hi-lo)/n
    s = fun(lo)+fun(hi)
    for k in range(1,n):
        s += (4 if k%2 else 2)*fun(lo+k*h)
    return s*h/3

I1 = simpson(lambda x: abs(gp(f(x))*fp(x)), 0, 2*math.pi)
I2 = simpson(lambda x: f(g(x))*gp(x), b, b+1/math.sqrt(c))
print('첫째 적분:', round(I1, 7), '이론값:', 160)
print('둘째 적분:', round(I2, 7))
print('둘째 적분 이론값:', round(b+1+(math.cos(a)-1)/a, 7))
print('f(2π):', round(f(2*math.pi), 7))
print('p+q:', 6)

Simpson 수치적분으로 두 적분과 최종 답을 확인합니다. 출력값은 부동소수점 오차에 따라 마지막 자리가 달라질 수 있습니다.

③ |g′(f(x)) f′(x)|

③ 그래프 아래 넓이는 첫 번째 적분값이며, ④ 그래프의 부호 있는 넓이는 두 번째 적분값입니다.

import numpy as np
import matplotlib.pyplot as plt

# 문항 10 : 함수와 정적분 그래프
# 설치: pip install numpy matplotlib
# 한글 제목 출력 (Windows)
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

a, b, c = 10, 4, 2
f = lambda x: -np.sin(a*x) + b + 1
g = lambda x: c*(x-b)**2
fp = lambda x: -a*np.cos(a*x)
gp = lambda x: 2*c*(x-b)

x = np.linspace(0, 2*np.pi, 2001)
t = np.linspace(b, b + 1/np.sqrt(c), 1001)
y1 = f(x)
y2 = g(f(x))
y3 = np.abs(gp(f(x))*fp(x))
y4 = f(g(t))*gp(t)

fig, axes = plt.subplots(2, 2, figsize=(12, 8))
items = [
    (axes[0,0], x, y1, 'f(x)', 'royalblue'),
    (axes[0,1], x, y2, 'g(f(x))', 'crimson'),
    (axes[1,0], x, y3, '|g\'(f(x)) f\'(x)|', 'seagreen'),
    (axes[1,1], t, y4, 'f(g(x)) g\'(x)', 'darkviolet'),
]
for ax, xx, yy, title, color in items:
    ax.plot(xx, yy, color=color, linewidth=2)
    ax.set_title(title)
    ax.axhline(0, color='gray', linewidth=0.8)
    ax.grid(alpha=0.25)
axes[1,0].fill_between(x, 0, y3, alpha=0.18, color='seagreen')
axes[1,1].fill_between(t, 0, y4, alpha=0.18, color='darkviolet')
fig.tight_layout()
plt.savefig('문항10_함수그래프.png', dpi=180, bbox_inches='tight')
plt.show()

# 수치 적분 확인 (NumPy 2.x에서도 사용 가능)
print('첫 번째 적분 ≈', np.trapezoid(y3, x))
print('두 번째 적분 ≈', np.trapezoid(y4, t))
print('f(2π) ≈', f(2*np.pi))
