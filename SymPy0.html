SymPy란?

SymPy는 수학식을 문자 그대로 다루는 파이썬 오픈소스 기호 계산 라이브러리입니다. 정확한 분수, 방정식의 해, 미분·적분·극한을 기호 형태로 구할 수 있습니다. NumPy의 수치 배열 계산과 구별됩니다.

설치: python -m pip install sympy matplotlib

그래프는 학습을 돕는 브라우저 미리보기이며, 실제 SymPy 그래프 출력은 하단의 파이썬 예제를 실행하세요. 그래프 일부는 시각화를 위한 대표 예시입니다.

각 함수 아래에 독립적으로 실행 가능한 관련 그래프 출력 코드 17개를 추가했습니다. 각 코드 실행 시 그래프가 표시되고 PNG 파일로 저장됩니다. NumPy와 Matplotlib도 필요합니다.

01 · 기호 변수

symbols

기호 변수를 정의하여 숫자를 대입하기 전에도 식을 다룰 수 있습니다.

실행 코드
파이썬 코드 복사
import sympy as sp
x = sp.symbols("x")
f = x**2 + 2*x + 1
print(f)
print(f.subs(x, 3))
예상 출력
x**2 + 2*x + 1
16
관련 그래프

이차함수 그래프에서 x=3일 때 함숫값은 16입니다.

관련 그래프 출력 파이썬 코드 01

기호식과 x=3에서의 점을 표시 (그래프 출력 및 PNG 저장)

파이썬 코드 복사
import sympy as sp
import numpy as np
import matplotlib.pyplot as plt

x = sp.symbols('x')
xs = np.linspace(-5, 5, 1200)
f = x**2+2*x+1
fn = sp.lambdify(x, f, 'numpy')
with np.errstate(divide='ignore', invalid='ignore'):
    ys = np.asarray(fn(xs), dtype=float)
plt.plot(xs, ys, label=str(f))
plt.scatter([3],[16],color='red',label='f(3)=16')
plt.axhline(0,color='gray',lw=.7)
plt.axvline(0,color='gray',lw=.7)
plt.grid(True); plt.legend()
plt.ylim(-12,20)
plt.title('SymPy example 01')
plt.tight_layout()
plt.savefig('sympy_01.png',dpi=160)
plt.show()
print('sympy_01.png 저장 완료')
02 · 식 정리

파이썬 코드 복사

예상 출력
x + 1
관련 그래프

원래 식은 x=1에서 정의되지 않습니다. 단순화 후에도 원래 정의역을 기억해야 합니다.

실습: 4개 그래프를 실제 PNG로 저장하기

아래 코드를 실행하면 함수·도함수·테일러 근사·원 그래프를 각각 PNG로 저장합니다. Matplotlib가 필요합니다.

파이썬 코드 복사
import sympy as sp
import matplotlib.pyplot as plt
import numpy as np
x, y = sp.symbols('x y')
functions = [x**2-2*x-3, sp.diff(x**3-3*x,x), sp.sin(x), sp.exp(x)]
xs = np.linspace(-4,4,500)
for i, f in enumerate(functions,1):
    fn = sp.lambdify(x,f,'numpy')
    yy = fn(xs)
    plt.figure(figsize=(7,4))
    plt.plot(xs,yy,label=str(f))
    plt.axhline(0,color='gray',lw=.7)
    plt.axvline(0,color='gray',lw=.7)
    plt.ylim(-10,10); plt.grid(True); plt.legend()
    plt.tight_layout(); plt.savefig(f'sympy_graph_{i}.png',dpi=160)
    plt.close()
print('4개 그래프 저장 완료')
4개 그래프 저장 완료

참고: 일부 기호식은 정의역·특이점 때문에 그래프를 그릴 때 추가 처리해야 합니다. SymPy의 plot과 plot_implicit도 함수별 예제에서 소개했습니다.
