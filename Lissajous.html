↑/↓ 속도 변경 · Space 일시정지/재생 · 곡선은 실시간으로 변화합니다.

매개변수 조절

수학적 정의

\(x(t)=270\sin(at+\phi)\)

\(y(t)=190\sin(bt)\)

\(0\leq t\leq 2\pi\)

현재 위상: 0.000 rad

속도 값은 매 프레임 증가하는 위상(rad)입니다. 프레임 간격이 작을수록 갱신이 자주 일어납니다.

Python Turtle — 속도 조절 전체 코드

import turtle
import math

s = turtle.Screen()
s.title("리사주 곡선 속도 조절")
s.setup(750, 550)
s.tracer(0)

p = turtle.Turtle()
p.hideturtle()
p.speed(0)
p.pensize(2)
p.color("blue")

phase = 0
speed = 0.03
paused = False

def faster():
    global speed
    speed = min(speed + 0.01, 0.3)
    print(f"속도 증가: {speed:.2f}")

def slower():
    global speed
    speed = max(speed - 0.01, 0)
    print(f"속도 감소: {speed:.2f}")

def pause():
    global paused
    paused = not paused
    print("일시정지" if paused else "재생")

s.listen()
s.onkey(faster, "Up")
s.onkey(slower, "Down")
s.onkey(pause, "space")

def draw():
    global phase
    if not paused:
        p.clear()
        p.penup()
        for i in range(501):
            t = 2 * math.pi * i / 500
            x = 270 * math.sin(3*t + phase)
            y = 190 * math.sin(2*t)
            p.goto(x, y)
            if i == 0:
                p.pendown()
        phase += speed
        s.update()
    s.ontimer(draw, 30)

draw()
s.mainloop()
