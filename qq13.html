서술형 13번 심층 풀이 및 파이썬 해석

1. 원본 문항 (Original Problem)

13. 다항함수 \(f(x)\)가 \(f'(0) = 1\)이고 모든 실수 \(x\)에 대하여

\[ f(x) = (f'(x) + 2)(f'(x) - 2) \]

를 만족시킬 때, \(f(4)\)의 값은? [4점]

① 1 ② 3 ③ 5 ④ 7 ⑤ 9

2. 꼼꼼하게 논리적으로 손으로 풀기 (Step-by-Step Solution)

단계 1: 다항함수 \(f(x)\)의 차수(Degree) 결정

주어진 항등식은 다음과 같이 정리할 수 있습니다:

\[ f(x) = (f'(x))^2 - 4 \]

다항함수 \(f(x)\)의 차수를 \(n\) (\(n \ge 0\))이라 합시다.

  • 만약 \(n = 0\) (상수함수)라면, \(f'(x) = 0\)이므로 \(f(x) = -4\)가 됩니다. 그러나 조건에서 \(f'(0) = 1\)이라 했으므로 모순입니다.
  • 만약 \(n \ge 1\)이라면, 좌변 \(f(x)\)의 차수는 \(n\)이고, 우변 \((f'(x))^2 - 4\)의 차수는 \(2(n - 1)\)입니다.

모든 실수 \(x\)에 대해 성립해야 하므로 양변의 차수가 같아야 합니다:

\[ n = 2(n - 1) \implies n = 2n - 2 \implies n = 2 \]

따라서 \(f(x)\)는 2차함수입니다.

단계 2: 계수 설정 및 미분계수 조건 적용

\(f(x)\)가 2차함수이므로 계수를 다음과 같이 설정합니다:

\[ f(x) = ax^2 + bx + c \quad (a \neq 0) \]

이를 미분하면,

\[ f'(x) = 2ax + b \]

조건 \(f'(0) = 1\)을 적용하면 \(b = 1\)임을 바로 얻습니다. 따라서 도함수는 다음과 같습니다:

\[ f'(x) = 2ax + 1 \]
단계 3: 항등식에 대입 및 계수비교법

\(f(x)\)와 \(f'(x)\)를 주어진 식 \(f(x) = (f'(x))^2 - 4\)에 대입합니다:

\[ ax^2 + x + c = (2ax + 1)^2 - 4 \]

우변을 전개하면,

\[ ax^2 + x + c = 4a^2 x^2 + 4ax + 1 - 4 = 4a^2 x^2 + 4ax - 3 \]

양변의 계수를 비교합니다:

  1. \(x^2\)의 계수: \(a = 4a^2 \implies a(1 - 4a) = 0\). \(a \neq 0\)이므로 \(a = \frac{1}{4}\)
  2. \(x\)의 계수: \(1 = 4a \implies 1 = 4 \times \frac{1}{4} = 1\) (성립)
  3. 상수항: \(c = -3\)

따라서 구하고자 하는 다항함수는 다음과 같습니다:

\[ f(x) = \frac{1}{4}x^2 + x - 3 \]
단계 4: \(f(4)\)의 값 계산 및 정답 도출

\(x = 4\)를 대입합니다:

\[ f(4) = \frac{1}{4}(4)^2 + 4 - 3 = 4 + 4 - 3 = 5 \]
정답: ③ 5

3. 그래프 시각화 및 파이썬 해석 (Graph & Python Interpretation)

함수 \(f(x) = \frac{1}{4}x^2 + x - 3\)과 도함수 \(f'(x) = \frac{1}{2}x + 1\)을 시각화한 정확한 벡터 SVG 그래프입니다.

파이썬 검증 코드 (SymPy):

import sympy as sp

# 변수 및 계수 정의
x = sp.Symbol('x')
a, b, c = sp.symbols('a b c', real=True)

# 2차 다항함수 f(x) 및 도함수 f'(x)
f = a*x**2 + b*x + c
df = sp.diff(f, x)

# 조건 1: f'(0) = 1
cond1 = sp.Eq(df.subs(x, 0), 1)

# 조건 2: f(x) = (f'(x)+2)(f'(x)-2)
diff_eq = f - ((df + 2)*(df - 2))
poly_eq = sp.Poly(diff_eq, x)

# 계수 방정식 생성 및 연립방정식 풀이
eqs = [cond1] + [sp.Eq(coeff, 0) for coeff in poly_eq.coeffs()]
sol = sp.solve(eqs, (a, b, c), dict=True)

valid_sol = [s for s in sol if s[a] != 0][0]
f_expr = valid_sol[a]*x**2 + valid_sol[b]*x + valid_sol[c]

print(f"구한 함수 f(x): {f_expr}")
print(f"f(4)의 값: {f_expr.subs(x, 4)}")
# 출력 결과: f(x) = x**2/4 + x - 3, f(4) = 5

4. 실생활 활용 예시 (Real-World Applications)

1. 물리학: 속도의 제곱에 비례하는 에너지 및 공기 저항 모델

물체의 위치 또는 에너지가 속도(도함수)의 제곱과 관련되는 미분방정식 구조입니다. 예를 들어 자동차나 항공기의 공기 저항력은 속도의 제곱(\(v^2\))에 비례하며, 역학적 에너지는 속도의 제곱으로 나타납니다. 운동 상태와 가속도, 위치 사이의 관계를 해석하는 근간이 됩니다.

2. 제어 공학 (Control Engineering)

로보틱스 및 드론 제어에서 시스템의 상태 변화율(도함수)의 제곱을 비용 함수(Cost Function)로 두고 이를 최적화할 때 이와 같은 이차 미분 관계식이 등장합니다.

3. 경제학: 한계비용 기반 총비용 함수 추정

생산량 \(x\)에 따른 총비용 함수 \(f(x)\)와 한계비용 \(f'(x)\) 사이에서, 한계비용의 제곱에 따라 비용 효율이 변하는 경제 모델의 최적 생산 지점을 산출할 때 활용됩니다.

4. 광학 및 안테나 설계 (Parabolic Reflector)

2차 함수 포물선은 빛과 파동을 한 점(초점)으로 모으는 성질이 있어, 파라볼라 안테나, 태양열 집열기, 자동차 헤드라이트의 반사경 설계에 직접 활용됩니다.
