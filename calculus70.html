01. 미분의 정의와 기본 법칙 8개

01. 도함수 정의 — 단계별 증명
\(f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}\)

단계별 증명

\[\begin{aligned}\frac{f(x+h)-f(x)}h\xrightarrow[h\to0]{}f'(x)\end{aligned}\]

두 점을 잇는 할선의 기울기의 극한으로 접선 기울기를 정의한다. 극한이 존재해야 한다.

02. 상수 — 단계별 증명
\(\frac{d}{dx}c=0\)

단계별 증명

\[\begin{aligned}\frac{c-c}{h}=0\quad\Longrightarrow\quad\lim_{h\to0}0=0\end{aligned}\]

상수함수는 모든 증가량에서 함수값의 변화가 없다.

03. 거듭제곱 — 단계별 증명
\(\frac{d}{dx}x^n=nx^{n-1}\)

단계별 증명

\[\begin{aligned}\frac{(x+h)^n-x^n}{h}=\sum_{k=1}^n\binom nk x^{n-k}h^{k-1}\xrightarrow[h\to0]{}nx^{n-1}\end{aligned}\]

자연수 지수는 이항정리로 증명한다. 음의 정수는 역수 법칙, 실수 지수는 지수·로그 법칙으로 확장한다.

04. 상수배 — 단계별 증명
\((cf)'=cf'\)

단계별 증명

\[\begin{aligned}\frac{cf(x+h)-cf(x)}h=c\frac{f(x+h)-f(x)}h\to cf'(x)\end{aligned}\]

극한의 상수배 법칙을 사용한다.

05. 합과 차 — 단계별 증명
\((f\pm g)'=f'\pm g'\)

단계별 증명

\[\begin{aligned}\frac{(f\pm g)(x+h)-(f\pm g)(x)}h=\frac{\Delta f}{h}\pm\frac{\Delta g}{h}\to f'\pm g'\end{aligned}\]

극한의 합·차 법칙을 사용한다.

06. 곱 — 단계별 증명
\((fg)'=f'g+fg'\)

단계별 증명

\[\begin{aligned}\frac{\Delta(fg)}h=\frac{\Delta f}h g(x+h)+f(x)\frac{\Delta g}h\to f'g+fg'\end{aligned}\]

중간항을 더하고 빼서 분해한다. 미분가능하면 연속이므로 g(x+h)→g(x).

07. 몫 — 단계별 증명
\(\left(\frac fg\right)'=\frac{f'g-fg'}{g^2}\)

단계별 증명

\[\begin{aligned}\left(\frac1g\right)'=\lim_{h\to0}\frac{g(x)-g(x+h)}{h\,g(x+h)g(x)}=-\frac{g'}{g^2}\\[3pt]\left(\frac fg\right)'=f'\frac1g+f\left(\frac1g\right)'=\frac{f'g-fg'}{g^2}\end{aligned}\]

g(x)≠0이고 근방에서 g가 0이 아니어야 한다.

08. 연쇄법칙 — 단계별 증명
\([f(g(x))]'=f'(g(x))g'(x)\)

단계별 증명

\[\begin{aligned}\Delta g=g(x+h)-g(x),\quad f(g+\Delta g)-f(g)=f'(g)\Delta g+o(|\Delta g|)\\[3pt]\frac{\Delta(f\circ g)}h=f'(g)\frac{\Delta g}h+\frac{o(|\Delta g|)}h\to f'(g)g'\end{aligned}\]

미분가능성의 선형근사를 쓰면 Δg=0인 경우에도 성립한다.

02. 다항·유리·무리·절댓값 7개

01. 일차식의 거듭제곱 — 단계별 증명
\([(ax+b)^n]'=na(ax+b)^{n-1}\)

단계별 증명

\[\begin{aligned}u=ax+b,\quad u'=a\\[3pt]\frac d{dx}u^n=nu^{n-1}u'=na(ax+b)^{n-1}\end{aligned}\]

거듭제곱 법칙과 연쇄법칙을 결합한다.

02. 역수 — 단계별 증명
\(\left(\frac1x\right)'=-\frac1{x^2}\)

단계별 증명

\[\begin{aligned}\frac{\frac1{x+h}-\frac1x}{h}=\frac{-h}{hx(x+h)}=-\frac1{x(x+h)}\to-\frac1{x^2}\end{aligned}\]

x≠0인 점에서 차분몫을 직접 계산한다.

03. 일반 역수 — 단계별 증명
\(\left(\frac1{u}\right)'=-\frac{u'}{u^2}\)

단계별 증명

\[\begin{aligned}\left(\frac1u\right)'=\frac{0\cdot u-1\cdot u'}{u^2}=-\frac{u'}{u^2}\end{aligned}\]

몫의 법칙을 분자 1, 분모 u에 적용한다.

04. 제곱근 — 단계별 증명
\((\sqrt{x})'=\frac1{2\sqrt{x}}\)

단계별 증명

\[\begin{aligned}\frac{\sqrt{x+h}-\sqrt x}{h}=\frac1{\sqrt{x+h}+\sqrt x}\to\frac1{2\sqrt x}\end{aligned}\]

분자 유리화로 직접 증명한다. x>0.

05. 합성 제곱근 — 단계별 증명
\((\sqrt{u})'=\frac{u'}{2\sqrt{u}}\)

단계별 증명

\[\begin{aligned}\frac d{dx}\sqrt{u}=\frac d{du}\sqrt u\cdot u'=\frac{u'}{2\sqrt u}\end{aligned}\]

제곱근의 미분과 연쇄법칙을 적용한다. u>0.

06. 절댓값 — 단계별 증명
\((|x|)'=\frac{x}{|x|}\)

단계별 증명

\[\begin{aligned}|x|=\begin{cases}x&(x>0)\\-x&(x<0)\end{cases}\quad\Longrightarrow\quad (|x|)'=\begin{cases}1&(x>0)\\-1&(x<0)\end{cases}=\frac{x}{|x|}\end{aligned}\]

0에서 우미분계수 1, 좌미분계수 −1로 달라 미분 불가능하다.

07. 일반 거듭제곱 — 단계별 증명
\((u^\alpha)'=\alpha u^{\alpha-1}u'\)

단계별 증명

\[\begin{aligned}u^\alpha=e^{\alpha\ln u}\\[3pt]\frac d{dx}u^\alpha=e^{\alpha\ln u}\,\alpha\frac{u'}u=\alpha u^{\alpha-1}u'\end{aligned}\]

일반 실수 α의 경우 u>0에서 로그로 유도한다.

03. 지수함수와 로그함수 9개

01. 자연지수 — 단계별 증명
\((e^x)'=e^x\)

단계별 증명

\[\begin{aligned}\frac{e^{x+h}-e^x}h=e^x\frac{e^h-1}h\to e^x\end{aligned}\]

자연로그의 역함수인 지수함수에 대해 기본 극한 lim (e^h−1)/h=1을 사용한다.

02. 밑 a 지수 — 단계별 증명
\((a^x)'=a^x\ln a\)

단계별 증명

\[\begin{aligned}a^x=e^{x\ln a}\quad\Longrightarrow\quad (a^x)'=e^{x\ln a}\ln a=a^x\ln a\end{aligned}\]

a>0; a=1도 식은 성립하지만 보통 일반지수의 밑에서 제외한다.

03. 합성 지수 — 단계별 증명
\((e^u)'=e^u u'\)

단계별 증명

\[\begin{aligned}\frac d{dx}e^{u(x)}=e^{u(x)}\frac{du}{dx}\end{aligned}\]

바깥 지수함수의 미분에 내부 도함수를 곱한다.

04. 합성 일반지수 — 단계별 증명
\((a^u)'=a^u\ln(a)u'\)

단계별 증명

\[\begin{aligned}a^{u}=e^{u\ln a}\quad\Longrightarrow\quad (a^u)'=e^{u\ln a}\ln a\,u'\end{aligned}\]

밑 a>0인 상수이다.

05. 자연로그 — 단계별 증명
\((\ln x)'=\frac1x\)

단계별 증명

\[\begin{aligned}y=\ln x\iff x=e^y\\[3pt]1=e^y y'=xy'\quad\Longrightarrow\quad y'=\frac1x\end{aligned}\]

역함수의 관계를 음함수 미분한다. x>0.

06. 절댓값 로그 — 단계별 증명
\((\ln|x|)'=\frac1x\)

단계별 증명

\[\begin{aligned}x>0:\ (\ln|x|)'=(\ln x)'=\frac1x\\[3pt]x<0:\ (\ln|x|)'=(\ln(-x))'=\frac{-1}{-x}=\frac1x\end{aligned}\]

정의역 x≠0을 두 구간으로 나누어 증명한다.

07. 일반 로그 — 단계별 증명
\((\log_a x)'=\frac1{x\ln a}\)

단계별 증명

\[\begin{aligned}\log_a x=\frac{\ln x}{\ln a}\quad\Longrightarrow\quad (\log_a x)'=\frac1{\ln a}\frac1x\end{aligned}\]

a>0, a≠1, x>0.

08. 합성 로그 — 단계별 증명
\((\ln|u|)'=\frac{u'}u\)

단계별 증명

\[\begin{aligned}\frac d{dx}\ln|u|=\frac1u\cdot u'=\frac{u'}u\end{aligned}\]

u≠0이고 u가 미분가능하면 부호가 국소적으로 일정하다.

09. 변수 밑과 지수 — 단계별 증명
\((u^v)'=u^v\left(v'\ln u+v\frac{u'}u\right)\)

단계별 증명

\[\begin{aligned}y=u^v,\quad\ln y=v\ln u\\[3pt]\frac{y'}y=v'\ln u+v\frac{u'}u\\[3pt]y'=u^v\left(v'\ln u+v\frac{u'}u\right)\end{aligned}\]

u>0일 때 양변에 로그를 취해 곱의 법칙을 적용한다.

04. 삼각함수 9개

01. 사인 — 단계별 증명
\((\sin x)'=\cos x\)

단계별 증명

\[\begin{aligned}\frac{\sin(x+h)-\sin x}h=\sin x\frac{\cos h-1}h+\cos x\frac{\sin h}h\to\cos x\end{aligned}\]

라디안 기준 lim sin h/h=1, lim (cos h−1)/h=0을 사용한다.

02. 코사인 — 단계별 증명
\((\cos x)'=-\sin x\)

단계별 증명

\[\begin{aligned}\frac{\cos(x+h)-\cos x}h=\cos x\frac{\cos h-1}h-\sin x\frac{\sin h}h\to-\sin x\end{aligned}\]

덧셈정리와 두 기본 삼각극한을 사용한다.

03. 탄젠트 — 단계별 증명
\((\tan x)'=\sec^2x\)

단계별 증명

\[\begin{aligned}(\tan x)'=\left(\frac{\sin x}{\cos x}\right)'=\frac{\cos^2x+\sin^2x}{\cos^2x}=\sec^2x\end{aligned}\]

cos x≠0.

04. 코탄젠트 — 단계별 증명
\((\cot x)'=-\csc^2x\)

단계별 증명

\[\begin{aligned}(\cot x)'=\left(\frac{\cos x}{\sin x}\right)'=\frac{-\sin^2x-\cos^2x}{\sin^2x}=-\csc^2x\end{aligned}\]

sin x≠0.

05. 시컨트 — 단계별 증명
\((\sec x)'=\sec x\tan x\)

단계별 증명

\[\begin{aligned}(\sec x)'=\left(\frac1{\cos x}\right)'=\frac{\sin x}{\cos^2x}=\sec x\tan x\end{aligned}\]

cos x≠0.

06. 코시컨트 — 단계별 증명
\((\csc x)'=-\csc x\cot x\)

단계별 증명

\[\begin{aligned}(\csc x)'=\left(\frac1{\sin x}\right)'=-\frac{\cos x}{\sin^2x}=-\csc x\cot x\end{aligned}\]

sin x≠0.

07. 합성 사인 — 단계별 증명
\((\sin u)'=\cos(u)u'\)

단계별 증명

\[\begin{aligned}\frac d{dx}\sin(u(x))=\cos(u(x))\,u'(x)\end{aligned}\]

사인의 미분에 연쇄법칙을 적용한다.

08. 합성 코사인 — 단계별 증명
\((\cos u)'=-\sin(u)u'\)

단계별 증명

\[\begin{aligned}\frac d{dx}\cos(u(x))=-\sin(u(x))\,u'(x)\end{aligned}\]

코사인의 미분에 연쇄법칙을 적용한다.

09. 합성 탄젠트 — 단계별 증명
\((\tan u)'=\sec^2(u)u'\)

단계별 증명

\[\begin{aligned}\frac d{dx}\tan(u(x))=\sec^2(u(x))\,u'(x)\end{aligned}\]

cos u≠0인 구간에서 연쇄법칙을 적용한다.

05. 역삼각함수 7개

01. 아크사인 — 단계별 증명
\((\arcsin x)'=\frac1{\sqrt{1-x^2}}\)

단계별 증명

\[\begin{aligned}y=\arcsin x\iff\sin y=x\\[3pt]\cos y\,y'=1,\quad \cos y=\sqrt{1-x^2}\\[3pt]y'=\frac1{\sqrt{1-x^2}}\end{aligned}\]

주값 y∈[−π/2,π/2], |x|<1.

02. 아크코사인 — 단계별 증명
\((\arccos x)'=-\frac1{\sqrt{1-x^2}}\)

단계별 증명

\[\begin{aligned}y=\arccos x\iff\cos y=x\\[3pt]-\sin y\,y'=1,\quad\sin y=\sqrt{1-x^2}\\[3pt]y'=-\frac1{\sqrt{1-x^2}}\end{aligned}\]

주값 y∈[0,π], |x|<1.

03. 아크탄젠트 — 단계별 증명
\((\arctan x)'=\frac1{1+x^2}\)

단계별 증명

\[\begin{aligned}y=\arctan x\iff\tan y=x\\[3pt]\sec^2y\,y'=1,\quad\sec^2y=1+x^2\\[3pt]y'=\frac1{1+x^2}\end{aligned}\]

주값 y∈(−π/2,π/2).

04. 아크코탄젠트 — 단계별 증명
\((\operatorname{arccot}x)'=-\frac1{1+x^2}\)

단계별 증명

\[\begin{aligned}y=\operatorname{arccot}x\iff\cot y=x\\[3pt]-\csc^2y\,y'=1,\quad\csc^2y=1+x^2\\[3pt]y'=-\frac1{1+x^2}\end{aligned}\]

arccot의 주값 범위 (0,π)를 채택한다.

05. 아크시컨트 — 단계별 증명
\((\operatorname{arcsec}x)'=\frac1{|x|\sqrt{x^2-1}}\)

단계별 증명

\[\begin{aligned}\sec y=x\ \Longrightarrow\ \sec y\tan y\,y'=1\\[3pt]|\sec y\tan y|=|x|\sqrt{x^2-1}\\[3pt]y'=\frac1{|x|\sqrt{x^2-1}}\end{aligned}\]

arcsec의 주값 y∈[0,π], y≠π/2에서 sec y tan y>0; |x|>1.

06. 아크코시컨트 — 단계별 증명
\((\operatorname{arccsc}x)'=-\frac1{|x|\sqrt{x^2-1}}\)

단계별 증명

\[\begin{aligned}\csc y=x\ \Longrightarrow\ -\csc y\cot y\,y'=1\\[3pt]\csc y\cot y=|x|\sqrt{x^2-1}\\[3pt]y'=-\frac1{|x|\sqrt{x^2-1}}\end{aligned}\]

arccsc의 주값 y∈[−π/2,0)∪(0,π/2]에서 |x|>1.

07. 합성 아크탄젠트 — 단계별 증명
\((\arctan u)'=\frac{u'}{1+u^2}\)

단계별 증명

\[\begin{aligned}\frac d{dx}\arctan(u(x))=\frac1{1+u(x)^2}\,u'(x)\end{aligned}\]

역탄젠트 미분에 연쇄법칙을 적용한다.

06. 쌍곡선함수와 역쌍곡선함수 9개

01. sinh — 단계별 증명
\((\sinh x)'=\cosh x\)

단계별 증명

\[\begin{aligned}\sinh x=\frac{e^x-e^{-x}}2\\[3pt](\sinh x)'=\frac{e^x+e^{-x}}2=\cosh x\end{aligned}\]

지수함수와 합성함수 미분을 사용한다.

02. cosh — 단계별 증명
\((\cosh x)'=\sinh x\)

단계별 증명

\[\begin{aligned}\cosh x=\frac{e^x+e^{-x}}2\\[3pt](\cosh x)'=\frac{e^x-e^{-x}}2=\sinh x\end{aligned}\]

지수함수와 합성함수 미분을 사용한다.

03. tanh — 단계별 증명
\((\tanh x)'=\operatorname{sech}^2x\)

단계별 증명

\[\begin{aligned}(\tanh x)'=\left(\frac{\sinh x}{\cosh x}\right)'=\frac{\cosh^2x-\sinh^2x}{\cosh^2x}=\operatorname{sech}^2x\end{aligned}\]

항등식 cosh²x−sinh²x=1을 이용한다.

04. coth — 단계별 증명
\((\coth x)'=-\operatorname{csch}^2x\)

단계별 증명

\[\begin{aligned}(\coth x)'=\left(\frac{\cosh x}{\sinh x}\right)'=\frac{\sinh^2x-\cosh^2x}{\sinh^2x}=-\operatorname{csch}^2x\end{aligned}\]

x≠0.

05. sech — 단계별 증명
\((\operatorname{sech}x)'=-\operatorname{sech}x\tanh x\)

단계별 증명

\[\begin{aligned}(\operatorname{sech}x)'=\left(\frac1{\cosh x}\right)'=-\frac{\sinh x}{\cosh^2x}=-\operatorname{sech}x\tanh x\end{aligned}\]

역수의 미분을 사용한다.

06. csch — 단계별 증명
\((\operatorname{csch}x)'=-\operatorname{csch}x\coth x\)

단계별 증명

\[\begin{aligned}(\operatorname{csch}x)'=\left(\frac1{\sinh x}\right)'=-\frac{\cosh x}{\sinh^2x}=-\operatorname{csch}x\coth x\end{aligned}\]

x≠0.

07. arsinh — 단계별 증명
\((\operatorname{arsinh}x)'=\frac1{\sqrt{x^2+1}}\)

단계별 증명

\[\begin{aligned}y=\operatorname{arsinh}x\iff\sinh y=x\\[3pt]\cosh y\,y'=1,\quad\cosh y=\sqrt{1+x^2}\\[3pt]y'=\frac1{\sqrt{1+x^2}}\end{aligned}\]

cosh y는 양수이다.

08. arcosh — 단계별 증명
\((\operatorname{arcosh}x)'=\frac1{\sqrt{x^2-1}}\)

단계별 증명

\[\begin{aligned}y=\operatorname{arcosh}x\iff\cosh y=x\\[3pt]\sinh y\,y'=1,\quad\sinh y=\sqrt{x^2-1}\\[3pt]y'=\frac1{\sqrt{x^2-1}}\end{aligned}\]

주값 y≥0, x>1.

09. artanh — 단계별 증명
\((\operatorname{artanh}x)'=\frac1{1-x^2}\)

단계별 증명

\[\begin{aligned}y=\operatorname{artanh}x\iff\tanh y=x\\[3pt](1-\tanh^2y)y'=1\\[3pt]y'=\frac1{1-x^2}\end{aligned}\]

|x|<1.

07. 음함수·역함수·매개변수 5개

01. 음함수 — 단계별 증명
\(F(x,y)=0\Rightarrow\frac{dy}{dx}=-\frac{F_x}{F_y}\)

단계별 증명

\[\begin{aligned}F(x,y(x))=0\\[3pt]\frac d{dx}F(x,y(x))=F_x+F_y y'=0\\[3pt]y'=-\frac{F_x}{F_y}\end{aligned}\]

F가 C¹이고 F_y≠0이면 음함수정리에 의해 국소적으로 y(x)가 존재한다.

02. 역함수 — 단계별 증명
\((f^{-1})'(x)=\frac1{f'(f^{-1}(x))}\)

단계별 증명

\[\begin{aligned}g=f^{-1},\quad f(g(x))=x\\[3pt]f'(g(x))g'(x)=1\\[3pt]g'(x)=\frac1{f'(g(x))}\end{aligned}\]

f가 국소적으로 역함수를 가지며 f'≠0인 점에서 성립한다.

03. 매개변수 — 단계별 증명
\(\frac{dy}{dx}=\frac{dy/dt}{dx/dt}\)

단계별 증명

\[\begin{aligned}x=x(t),\quad y=y(t)\\[3pt]\frac{dy}{dt}=\frac{dy}{dx}\frac{dx}{dt}\\[3pt]\frac{dy}{dx}=\frac{y'(t)}{x'(t)}\end{aligned}\]

x'(t)≠0이면 x를 국소 매개변수로 사용할 수 있다.

04. 매개변수 이계 — 단계별 증명
\(\frac{d^2y}{dx^2}=\frac{\frac d{dt}(dy/dx)}{dx/dt}\)

단계별 증명

\[\begin{aligned}\frac{d^2y}{dx^2}=\frac d{dx}\left(\frac{y'}{x'}\right)=\frac1{x'}\frac d{dt}\left(\frac{y'}{x'}\right)\\[3pt]=\frac{y''x'-y'x''}{(x')^3}\end{aligned}\]

여기서 프라임은 t에 대한 미분이며 x'≠0이다.

05. 극좌표 기울기 — 단계별 증명
\(\frac{dy}{dx}=\frac{r'\sin\theta+r\cos\theta}{r'\cos\theta-r\sin\theta}\)

단계별 증명

\[\begin{aligned}x=r(\theta)\cos\theta,\quad y=r(\theta)\sin\theta\\[3pt]\frac{dx}{d\theta}=r'\cos\theta-r\sin\theta\\[3pt]\frac{dy}{d\theta}=r'\sin\theta+r\cos\theta\\[3pt]\frac{dy}{dx}=\frac{r'\sin\theta+r\cos\theta}{r'\cos\theta-r\sin\theta}\end{aligned}\]

분모 dx/dθ≠0인 점에서 성립한다.

08. 고계도함수·편미분·다변수 8개

01. 이계도함수 — 단계별 증명
\(f''(x)=\frac{d^2f}{dx^2}\)

단계별 증명

\[\begin{aligned}f''(x):=(f'(x))'=\lim_{h\to0}\frac{f'(x+h)-f'(x)}h\end{aligned}\]

정의의 반복 적용이다. 두 번째 미분가능성이 필요하다.

02. n계도함수 — 단계별 증명
\(f^{(n)}(x)=\frac{d^nf}{dx^n}\)

단계별 증명

\[\begin{aligned}f^{(0)}=f,\quad f^{(n)}=\frac d{dx}f^{(n-1)}\\[3pt]f^{(n)}=\underbrace{\frac d{dx}\cdots\frac d{dx}}_{n\text{회}}f\end{aligned}\]

수학적 귀납적 정의로 n계 도함수를 만든다.

03. 편미분 — 단계별 증명
\(f_x=\frac{\partial f}{\partial x},\quad f_y=\frac{\partial f}{\partial y}\)

단계별 증명

\[\begin{aligned}f_x(x,y)=\lim_{h\to0}\frac{f(x+h,y)-f(x,y)}h\\[3pt]f_y(x,y)=\lim_{h\to0}\frac{f(x,y+h)-f(x,y)}h\end{aligned}\]

한 좌표를 고정하여 각각 차분몫을 계산한다.

04. 전미분 — 단계별 증명
\(df=f_x\,dx+f_y\,dy\)

단계별 증명

\[\begin{aligned}\Delta f=f_x\Delta x+f_y\Delta y+o\!\left(\sqrt{(\Delta x)^2+(\Delta y)^2}\right)\\[3pt]df=f_x\,dx+f_y\,dy\end{aligned}\]

f가 해당 점에서 전미분 가능할 때 선형 부분을 전미분으로 정의한다.

05. 다변수 연쇄법칙 — 단계별 증명
\(\frac{dz}{dt}=f_x\frac{dx}{dt}+f_y\frac{dy}{dt}\)

단계별 증명

\[\begin{aligned}z(t)=f(x(t),y(t))\\[3pt]\Delta z=f_x\Delta x+f_y\Delta y+o(\sqrt{\Delta x^2+\Delta y^2})\\[3pt]\frac{dz}{dt}=f_x x'(t)+f_y y'(t)\end{aligned}\]

f의 전미분가능성과 x,y의 미분가능성을 사용한다.

06. 기울기 벡터 — 단계별 증명
\(\nabla f=(f_x,f_y,f_z)\)

단계별 증명

\[\begin{aligned}df=f_x\,dx+f_y\,dy+f_z\,dz\\[3pt]\nabla f:=\left(\frac{\partial f}{\partial x},\frac{\partial f}{\partial y},\frac{\partial f}{\partial z}\right)\end{aligned}\]

기울기는 선형근사의 계수들을 모은 벡터로 정의된다.

07. 방향도함수 — 단계별 증명
\(D_{\mathbf u}f=\nabla f\cdot\mathbf u\)

단계별 증명

\[\begin{aligned}D_{\mathbf u}f(\mathbf p)=\lim_{t\to0}\frac{f(\mathbf p+t\mathbf u)-f(\mathbf p)}t\\[3pt]=\nabla f(\mathbf p)\cdot\mathbf u\end{aligned}\]

f가 전미분가능하고 u가 단위벡터일 때 성립한다.

08. 혼합편도함수 — 단계별 증명
\(f_{xy}=f_{yx}\)

단계별 증명

\[\begin{aligned}\Delta_{h,k}f=f(x+h,y+k)-f(x+h,y)-f(x,y+k)+f(x,y)\\[3pt]\frac{\Delta_{h,k}f}{hk}\xrightarrow[h,k\to0]{}f_{xy}(x,y)=f_{yx}(x,y)\end{aligned}\]

근방에서 이계 편도함수들이 연속이면 평균값정리를 두 순서로 적용해 같은 극한을 얻는다.

09. 미분의 응용과 특수 공식 8개

01. 접선 — 단계별 증명
\(y-f(a)=f'(a)(x-a)\)

단계별 증명

\[\begin{aligned}m=\lim_{x\to a}\frac{f(x)-f(a)}{x-a}=f'(a)\\[3pt]y-f(a)=m(x-a)=f'(a)(x-a)\end{aligned}\]

접선은 (a,f(a))를 지나고 기울기가 f'(a)인 직선이다.

02. 법선 기울기 — 단계별 증명
\(m_n=-\frac1{f'(a)}\)

단계별 증명

\[\begin{aligned}m_t=f'(a),\quad m_t m_n=-1\\[3pt]m_n=-\frac1{f'(a)}\end{aligned}\]

f'(a)≠0인 경우. f'(a)=0이면 법선은 수직선 x=a이다.

03. 선형근사 — 단계별 증명
\(f(a+h)\approx f(a)+f'(a)h\)

단계별 증명

\[\begin{aligned}f'(a)=\lim_{h\to0}\frac{f(a+h)-f(a)}h\\[3pt]f(a+h)=f(a)+f'(a)h+o(h)\\[3pt]f(a+h)\approx f(a)+f'(a)h\end{aligned}\]

오차항 o(h)는 h에 비해 더 빠르게 0으로 간다.

04. 뉴턴 방법 — 단계별 증명
\(x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}\)

단계별 증명

\[\begin{aligned}0\approx f(x_n)+f'(x_n)(x_{n+1}-x_n)\\[3pt]x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}\end{aligned}\]

현재 점의 접선과 x축의 교점을 다음 근삿값으로 택한다. 수렴은 별도 조건이 필요하다.

05. 로그미분 — 단계별 증명
\(\frac{y'}y=\frac d{dx}\ln|y|\)

단계별 증명

\[\begin{aligned}\frac d{dx}\ln|y(x)|=\frac{y'(x)}{y(x)}\\[3pt]\frac{y'}y=\frac d{dx}\ln|y|\end{aligned}\]

y≠0인 구간에서 로그의 연쇄법칙을 사용한다.

06. 라이프니츠 곱의 n계 미분 — 단계별 증명
\((fg)^{(n)}=\sum_{k=0}^n\binom nk f^{(k)}g^{(n-k)}\)

단계별 증명

\[\begin{aligned}(fg)^{(n)}=\sum_{k=0}^n\binom nk f^{(k)}g^{(n-k)}\\[3pt]\binom nk+\binom n{k-1}=\binom{n+1}k\end{aligned}\]

n=1에서 곱의 법칙으로 시작한다. 귀납 단계에서 각 항을 미분하고 파스칼 항등식으로 계수를 결합한다.

07. 적분 상한 미분 — 단계별 증명
\(\frac d{dx}\int_a^{g(x)}f(t)\,dt=f(g(x))g'(x)\)

단계별 증명

\[\begin{aligned}F(z)=\int_a^z f(t)\,dt,\quad F'(z)=f(z)\\[3pt]\frac d{dx}F(g(x))=F'(g(x))g'(x)=f(g(x))g'(x)\end{aligned}\]

f가 관련 구간에서 연속이고 g가 미분가능할 때 기본정리와 연쇄법칙을 적용한다.

08. 양 끝 가변 적분 — 단계별 증명
\(\frac d{dx}\int_{u(x)}^{v(x)}f(t)\,dt=f(v)v'-f(u)u'\)

단계별 증명

\[\begin{aligned}\int_{u(x)}^{v(x)}f(t)\,dt=F(v(x))-F(u(x))\\[3pt]\frac d{dx}\int_{u(x)}^{v(x)}f(t)\,dt=f(v(x))v'(x)-f(u(x))u'(x)\end{aligned}\]

F'=f를 만족하는 원시함수를 잡아 미분한다.
